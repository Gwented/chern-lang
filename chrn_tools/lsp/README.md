This exists because I don't have the time to develop and LSP on top of an already unfinished language, which is also acting as a learning experience itself to where I need to make sweeping changes at times, which would cause an impossible work-load to upkeep.

This is also extremely integral to the development process at this point since something like variable dependency tracking and whether or not spanning over-indexing is done can be done rapidly since an LSP in comparison to running the compiler each time is far more productive.
