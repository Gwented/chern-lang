E0001: Config load error

.chrn files go through an initial region loading stage to ensure

Covers

  • @def with no matching @end.
  • A source region over the 32KB limit.
  • IO failures reading the config.

Valid usage of @def and @end

@def with @end

@def
var->
    x: i32
    y: i32
@end

Only @end

let chrn = "ch" + "ern"
let super_chrn = "super " + chrn
@end
